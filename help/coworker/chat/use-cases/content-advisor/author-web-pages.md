# Crear páginas de AEM Sites con Coworker

Use [Coworker](./overview.md), la inteligencia artificial aplicada a la conversación de Adobe, para crear páginas de AEM Sites describiendo lo que desea en un lenguaje sencillo en lugar de hacer clic en el editor de páginas.

En este vídeo, el compañero agrega una nueva promoción a la página principal de WKND, creada a partir de un fragmento de contenido visual, mediante un mensaje de chat.

>[!VIDEO](https://video.tv.adobe.com/v/3503863/?learn=on)

>[!NOTE]
>
>Este vídeo muestra a un compañero creando una página en un sitio basado en el Editor de páginas. Los compañeros de trabajo funcionan de la misma manera en los sitios que se entregan con Edge Delivery Services.

Consulte [Resumen de chat con compañeros](https://experienceleague.adobe.com/en/docs/cx-enterprise-ai/experience-cloud-ai/coworker/chat/overview) para comenzar a usar Chat con compañeros.
